01 · OVERVIEW

まず計算の構造を理解する

表示攻撃力だけで最終ダメージは決まりません。攻撃力から始まり、与ダメ補正、強打・連打などの判定、宝石、クリティカル、ブレイク、防御、カウンターといった複数のグループが連なります。

A・B
攻撃力

装備やバフを合わせた、表示攻撃力に近い部分。

C・D・E・F
火力補正

スキル威力、強打・連打、宝石タグ、クリティカル。

G〜L
状況補正

ブレイク、敵防御、カウンター、追加攻撃、最終補正。

推定ダメージ = ⌈ 2 × ダメージ幅(0.95〜1.05) × ⌊A×B⌋ × C × D × E × F × G × H × I × J × K × L × スキル係数 ⌉

⌊ ⌋ は切り捨て、⌈ ⌉ は切り上げ。出典のモデルでは基準威力に2倍の係数が含まれます。平均値・個別ヒット・クリティカルの期待値を混同しないでください。

例：カウンター成立 → J = 1.10敵がブレイク中 → Gを適用強打と連打が両方発生 → Dに加算

03 · FORMULAS

12の計算要素 A〜L

クリックで詳細が開きます。％入力の計算では「20%＝0.20」として扱います。

A・B基礎攻撃と攻撃％
C・D与ダメと判定強化
E〜H宝石・クリ・ノーガード・固有
I〜L防御・カウンター・追加・最終
A 攻撃力の基礎部分

キャラ自身の攻撃力、武器一式、首飾り、同行ペットの攻撃力、ファッションセット効果、固定値エンチャントなどを合わせます。武器側の内訳は基本攻撃力・刻印攻撃力・武器の印章効果・エンブレム補正・武器対応能力値のボーナスダメージです。

A = キャラ攻撃 + 武器一式 + 首飾り + ペット攻撃 + 衣装セット + 固定攻撃エンチャント
B 攻撃力％ボーナス

アイテム・スキル・エンチャントによる攻撃力％上昇を合計します。原資料では表示攻撃力を ⌊A×B⌋ と表現しています。

B = 1 + 装備の攻撃力% + スキルの攻撃力% + エンチャントの攻撃力%
C 与えるダメージ・受けるダメージ増加

スキル威力ステータスとスキルダメージ増加を掛け、その後に装備などの与ダメ増加分を加算するモデルです。敵側の被ダメ増加は別の倍率として扱います。各種シナジーは種類によって重複しない想定があります。

C = 与ダメ倍率 × 被ダメ倍率 与ダメ倍率 = (1 + スキル威力/8500) × (1 + スキルダメ増%) + ヘリオ% + 一部条件付き増% + 装備与ダメ% + 味方シナジー% 被ダメ倍率 = 1 + 防具破壊デバフ% + 被ダメ増シナジー%
D 強打・連打・マルチヒットなど

該当する判定が同時に出た場合の各強化分を、まず同一枠へ足すモデルです。判定ごとの個別倍率を単純に全部掛ける方式ではありません。

D = 1 + 連打補正 + 強打補正 + 広域補正 + コンボ補正 + 究極補正 連打補正 = (1 + 連打強化/8500) × (1 + 連打ダメ%) − 1 強打補正 = (1 + 強打強化/8500) × (1 + 強打ダメ%) − 1 広域補正 = (1 + 広域強化/8500) × (1 + 広域ダメ%) − 1 コンボ補正 = [(1 + コンボ強化/17500) × (1 + コンボダメ%) − 1] × (段階/4) 究極補正 = 究極技ステータス/8750 （究極技の一撃のみ）

コンボ段階の例：1コンボ、10コンボ、50コンボ、100コンボで段階1〜4。原資料では究極ゲージ回復について究極技ステータス/7250の増加モデルも記載。

E 宝石のスキルタグ
E = 1 + 対象スキルに効く宝石タグダメージ増加の合計%

元素・強打など、実際に使用したスキルが持つタグに対応する数値だけを計上します。緑色ヘリオドール由来のタグ増加もこの枠に含む想定です。

F クリティカル
クリティカル率 = min( 0.5 − 1/(2 + クリティカル/1000) + その他のクリ率%, 1 ) クリティカル倍率 = (1.4 + クリティカル/5000) × (1 + クリダメ増加%) F（期待値）= 1 + クリティカル率 × (クリティカル倍率 − 1) F（実際のヒット）= 非クリティカルなら1 ／ クリティカルなら倍率

追加クリ率にはルーン・キャラクター・各種ボーナスを含めます。下限は本計算機内では0にクランプしています。追加クリダメはルーンなどの合計値を入力します。

G ノーガード／ブレイク
G（ブレイク中）= (1 + ブレイク値/5250) × (1 + ノーガードダメ増%) + 0.20 + ブレイク種別のタグ補正 G（非ブレイク中）= 1

タグ補正は敵がどのブレイク状態になったか、攻撃側がどの判定・属性を持つかで変わります。例えばブローブレイクでは強打と連打がそれぞれ+10%、火傷と感電がそれぞれ+5%と記載されています。全部が同時に成立するとは限りません。

H スキル固有の係数増幅

特定のスキルダメージ増加説明が、与ダメ増加Cではなく別枠へ作用するケースがあります。どのルーン・バフがここに入るかはクラス別検証が必要です。本計算機では任意の独立乗数として入力できます。

H = スキル固有増幅の倍率（要個別検証）
I 敵防御の軽減
I = 1 / [1 + 敵防御力 × (1 − 防御減少・無視率) / 10328]

原資料の例：訓練用カカシ 30、グラスギブネン等 6410、アビス地獄2 9153、バリのアビス 15903。これらは原資料での検証用数値で、日本現行値とは限りません。

J カウンター
J = 1.10（カウンター成立） / 1.00（未成立）

敵がスキルを準備している間に攻撃が成立した場合の、最終ダメージ+10%モデルです。敵が「カウンター状態」にあることと、攻撃の「カウンター判定」は文脈上分けて扱ってください。

K 追加攻撃
K（平均期待値）= 1 + 追加攻撃ステータス/13000 K（単発の実ヒット）= 1

実際のヒットでは、追加の攻撃が発生したかどうかを別に評価する必要があります。「1発のダメージ×期待追加分」は平均火力を比較する近似です。

L 最終ダメージ増加
L = 1 + 最終ダメージ増加スキルの合計%

弓使いの弱点貫通、ダンサーのテンポなどが例示されています。Hとの関係（加算か乗算か）は原資料でも未確定です。

スキル係数のレベル補正

実効係数 = Lv0のスキル係数 × [1 + (0.03 × スキルLv) + (0.02 × 段階達成数)] 段階達成数：Lv2、10、15、20、30の各ラインを超えるごとに＋1

05 · STATS

基本能力値と戦闘能力値

STR・DEX・INT・WILL・LUCKは、それぞれ複数の戦闘能力値につながっています。武器の参照ステータスとレベルアップカードの配分も含めて考えましょう。

基礎能力値影響する代表的な能力意味
STR（力）強打強化、ダメージダウン、ブレイク大きい一撃・耐久・ブレイク関係
DEX（器用）連打強化、コンボ強化、速攻連続攻撃・通常攻撃速度
INT（知力）広域強化、スキル威力、スキル高速化複数対象・スキル威力・スキルの準備や使用速度
WILL（意志）追加HP、回復力、究極技最大HP・回復・究極技
LUCK（幸運）クリティカル、追加攻撃、急所回避会心や追撃・防御の確率性能

「速攻」は通常攻撃の速度に関係し、「スキル高速化」は詠唱・チャージ／使用の速度に関係します。いずれも無条件のスキルCT短縮ではありません。

サブ能力値の候補と数値

固定値取得→既存分の追加上昇→2つ目の追加取得、という流れで見てください。

増幅に使った素材は装備分解で返却されないという先行説明があります。性能改善では残す側（母体）の増幅情報が残り、素材側の増幅は移らない想定です。新しいエンチャントを付けても同じ装備の増幅状態は維持されます。

07 · EQUIPMENT

装備を評価するとき

装備の基本

武器・防具・アクセサリーを装着して攻撃力や防御力などを上げます。ダンジョン、狩場、ブラックホール、製作、ミスティックダイスなどが入手経路になります。

育成の入口

基礎攻撃・防御の高さだけでなく、宝石スロットの数も重要です。宝石とルーン刻印、刻印強化によって同じ装備でも性能が大きく変わります。

性能改善で迷ったら

強化して使っている母体側と、基礎値を取り込む素材側を区別しましょう。韓国側の説明では、エンチャント増幅は母体側の情報が残る扱いです。日本版では結果確認画面を優先してください。

08 · SPEED

スキルの準備と使用速度

スキルは「発動の準備」と「発動後の動作」に分けると理解しやすくなります。

① 準備する

詠唱やチャージでスキルを使える状態にする時間。詠唱・チャージ速度の補正が関係します。

② スキルを実行する

アニメーションや持続攻撃（チャネリング）の時間。スキル使用速度が関係し、チャネリングの効果発生間隔も変化する想定です。

スキル高速化は上記①②に幅広く影響する能力です。クールタイムを直接短くする能力とは区別してください。
